数据按原始来源分组。首轮预测前登记并冻结模型；随后修复视频分支注册和启动批量预热，保持同一权重、阈值、帧数与分辨率，复测同一100。交付目录再执行一次完整复测。不能把这些回放称为数次新的盲测。基础模型预训练交集未知，公开来源真实不是已确认合法理赔。

2个错误均为传统拼接：suite18_edit_image_04、suite18_edit_image_05。当前数据此后仅可回归，下一版要新来源盲测。

## 要求覆盖

| 命题要点 | 状态与可核验边界 |
|---|---|
| 图片与视频 | 两类均能安全上传、实际检测、保留原件并出报告 |
| ≥3 AIGC工具 | 当前测试有10个可追溯发布工具名称；不保证所有工具版本效果 |
| 传统篡改 | 复制、拼接、视频拼接链路具备；2份图片拼接仍漏检 |
| ≥95%、≤3%、≤5秒 | 仅本批混合公开研究测试同时满足 |
| 结论、置信度、区域、依据 | 原图掩码、分支证据、实际PTS、参考域概率和JSON/CSV/HTML具备 |
| 多模态、痕迹、元数据、ensemble | 均有实际计算；OCR和元数据疑点独立于欺诈真值 |
| 业务域全覆盖 | 未完成，84份文档专项仍弱；不能宣称全项正式验收 |
