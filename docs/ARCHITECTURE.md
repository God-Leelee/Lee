# 技术架构与处理流程

CF224冻结编码器的两整体视图与五个原始分辨率裁剪形成4608维表征，32隐藏单元MLP适配来源。图片生成与编辑分别校准，单调联合。视频条件证据树结合关键帧来源、连续窗口TCN、TruFor区域及一致性特征。SIFT+RANSAC附加光度可靠性，密集候选用真实RGB验证。

```mermaid
flowchart TD
 A[图片或视频上传] --> B[原件留存与SHA256]
 B --> C[安全解码与实际PTS]
 C --> D{材料类型}
 D -->|图片| E[CF来源适配与空间取证]
 D -->|视频| F[全局采样与连续窗口TCN]
 F --> G[来源检测与逐采样帧空间取证]
 E --> H[图片双风险头融合]
 G --> I[视频条件证据融合]
 C --> J[OCR图文核验与原始元数据]
 H --> K[独立校准与冻结阈值]
 I --> K
 K --> L[原始坐标与时间证据报告]
 J --> L
 E -->|必需分支失败| M[保留证据并返回部分完成]
 G -->|必需分支失败| M
 M --> L
```

## 研究验证流程

```mermaid
flowchart LR
 A[原始来源与案件分组] --> B[拟合分区]
 A --> C[独立校准分区]
 A --> D[阈值开发分区]
 B --> E[模型选择与训练]
 E --> F[概率校准]
 C --> F
 F --> G[阈值确定]
 D --> G
 G --> H[冻结源码权重配置]
 H --> I[新来源数据实测]
 I --> J[保留错误失败超时并报告]
```

标签、文件名、工具来源、编辑掩码不进入推理特征。数据增强与原件不跨分区。图文冲突和元数据缺失单独解释，不直接当作AI或欺诈真值。视频最多32个不同PTS帧，未采样间隔为未知，当前不做语音鉴伪。

前端React/Vite，后端FastAPI，PyAV媒体解码，RapidOCR文字提取，PyTorch视觉推理。材料与案件存本地目录和索引；服务仅监听127.0.0.1，无公网部署。
