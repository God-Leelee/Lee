# 数据、权重与公开范围

本仓库公开项目代码、固定参数配置、3份当前主链路的小型已训练权重、许可证及复现脚本。上游大模型由安装脚本从原始来源取得；代码公开不自动改变第三方模型或数据的授权条件。

## 排除内容

- 主办方微信119张图片及其下载会话、附件地址、账户信息。
- 微信辅助头的44份支持向量；这是与私有样本直接相关的特征，公开配置关闭该分支。
- 公开数据的原始媒体、训练特征缓存、OCR案件字段、上传原件、历史案件与报告全文。
- Python虚拟环境、npm依赖、第三方Git clone、大型上游权重、开发日志和历史ZIP。

公开源码未包含原始命题DOCX。命题文档只作为需求依据，仓库重点介绍实现与可验证结果。

## 授权输入与完整离线包

完整历史评测需要固定原件、真值、清单、模型、参数与运行器一同核验。权利未确认的素材不能仅因为竞赛用途或私有仓库就假定允许再分发。拟通过竞赛系统提供离线包时，应先逐项确认资料的提供范围；当前GitHub包只提供无第三方媒体的工程演示路线。

许可原文保留在 `licenses/upstream/` 和 `models/licenses/`。原始作者引用见 `THIRD_PARTY_NOTICES.md`；TruFor/WaveRep的信息及非营利使用条件继续适用。项目自有代码未被擅自设置成覆盖全部组件的MIT许可证。

本仓库仅本机启动，未进行公网部署。运行者自行上传的材料、原件与结果保存在本机 `data/cases/`，该目录由 `.gitignore` 排除。
