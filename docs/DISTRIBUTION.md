# 数据模型与公开范围

GitHub仓库保存代码和复现说明；同版本Release仅保存运行所需的两个模型包。比赛PPT、Word、现场脚本及效果验证资料由比赛提交渠道单独提交，不作为GitHub Release附件。

公开：项目代码、固定数值监督头、时序权重、原上游许可允许的非商业研究模型包、来源与哈希、程序自制样例、操作掩码、结果记录、截图、图示与说明。

不公开：119张医疗等原件、私有案件缓存、原始支持向量、HF令牌和登录态、授权文档原图与掩码、实验特征缓存、SPAI/CO-SPY未采用的大权重。开发资料本地保留，Git历史保留之前公开源码版本。

100套公开研究原图按发布者固定来源由restore_public100.py获取，包中只提供清单和重建脚本，不将来源权利未知的原媒体再分发。该路径需要网络及原发布者的可用性；取得数据后固定SHA核验。许可受限的文档专项要另行取得AIForge访问，原始文档不随公开包提供。

TruFor/WaveRep只声明信息与非营利用途，CF代码与模型卡MIT，具体依赖、数据及上游许可分别保留。自有代码按仓库LICENSE授权竞赛评审，未将所有资产一律标成MIT。源码与两个模型包即可还原运行资料，首次Python依赖安装仍需网络，不称全离线安装镜像。
