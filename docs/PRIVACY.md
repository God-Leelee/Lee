# 数据与隐私

## 默认行为

- 服务默认绑定 `127.0.0.1`，只接受本机访问。
- 上传材料、案件报告和派生证据保存在本机 `data/cases`。
- `data`、`runs`、虚拟环境和下载的大型权重均被 `.gitignore` 排除。
- 项目没有内置账户系统、云同步或遥测上报。

## 对外开放前

当前服务按本地单用户工作台设计。若要暴露到局域网或公网，需要额外增加身份认证、HTTPS、上传隔离、配额、恶意文件扫描、审计日志、数据保留策略和访问权限控制。

## 分享问题报告

提交 Issue 前请删除：

- 原始图片和视频
- 姓名、证件号、病历、地址等个人信息
- `data/cases` 中的案件目录
- 本地路径、访问令牌和环境变量

建议只附脱敏日志、软件版本、错误堆栈以及可公开分发的最小复现输入。
